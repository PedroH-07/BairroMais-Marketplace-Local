# 🛒 BairroMais - Marketplace Local

> Conectando pequenos produtores e comércios de bairro aos consumidores da região.

---

## 📌 Proposta de Valor
O **BairroMais** é uma solução para fortalecer a economia local. O aplicativo conecta moradores a feirantes, produtores artesanais e pequenos comércios de vizinhança, oferecendo uma alternativa de delivery simples e justa.

## 🎯 Problema e Solução
- **Problema:** Pequenos empreendedores locais não possuem visibilidade digital e sofrem com taxas elevadas das grandes plataformas de delivery.
- **Solução:** Um aplicativo nichado por bairro, com taxas reduzidas para o comerciante e busca inteligente focada na comunidade.

## 🚀 Funcionalidades do MVP
- [x] Tela Inicial com categorias e listagem dinâmica de comércios integrada à nuvem
- [x] Catálogo de produtos por loja buscado diretamente do banco de dados relacional
- [x] Carrinho de compras dinâmico com controlo de quantidades e subtotal reativo
- [x] Tela de resumo e finalização do pedido

## 🎨 Identidade Visual

## 🛠️ Tecnologias Utilizadas
- **Front-end:** Flutter & Dart (Executado via Web/Edge)
- **Back-end & Banco de Dados:** Supabase (PostgreSQL em nuvem)
- **Ferramentas:** Visual Studio Code

## ⚙️ Como Executar o Projeto

1. Clone o repositório para o seu computador:
   git clone <url-do-repositorio>

2. Abra a pasta do projeto no **Visual Studio Code**.

3. Certifique-se de que as dependências do Flutter estão atualizadas executando no terminal:
   flutter pub get

4. Execute a aplicação no navegador (Edge):
   flutter run -d edge
